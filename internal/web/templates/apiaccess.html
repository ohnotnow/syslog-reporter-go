A personal token lets Claude Code (with the syslog-reporter skill) and the syslog-mute shell function act as you. Use one token per machine, so a leak costs one token, not you.

The Claude Code skill

Download the skill and unzip it into ~/.claude/skills/, so you get ~/.claude/skills/syslog-reporter/SKILL.md. Then create a token below and paste its block into your settings, and ask Claude about the syslog report.

For Claude Code

Add this inside the outer braces of ~/.claude/settings.json (on Windows, %USERPROFILE%\.claude\settings.json). If you have no such file, create it with { and } around this. Claude Code then has it in every session.

"env": {
  "SYSLOG_API_URL": "{{$.Data.BaseURL}}",
  "SYSLOG_API_TOKEN": "{{.NewToken}}"
}

For the syslog-mute shell function

The function in the daily email runs in your own shell, so it needs the same two values there. bash or zsh (~/.bashrc or ~/.zshrc):

export SYSLOG_API_URL={{$.Data.BaseURL}}
export SYSLOG_API_TOKEN={{.NewToken}}

PowerShell ($PROFILE):

$env:SYSLOG_API_URL = "{{$.Data.BaseURL}}"
$env:SYSLOG_API_TOKEN = "{{.NewToken}}"

Check it

curl -sS -H "Authorization: Bearer $SYSLOG_API_TOKEN" "$SYSLOG_API_URL/api/me"
