# Bundled noise rules, loaded into the known_knowns table by
#   syslog-reporter knowns seed            (this embedded copy)
#   syslog-reporter knowns seed <file>     (an edited copy)
#
# One rule per line. A rule is a regex matched against the line after the
# hostname, i.e. 'program[pid]: message', the same text a known-known's
# --match sees. Lines starting with # are comments, blank lines are ignored.
# A '#' preceded by whitespace on a rule line starts that rule's reason.
# 'host=GLOB ' at the start of a rule limits it to matching hostnames;
# every other rule applies to host *. Literal text must be regex-quoted
# (a dot is \., brackets are \[ \]). Seeding skips rules already present
# and never deletes; remove a rule with 'knowns remove <id>'.
#
# Estate-identifying literals (your hostnames, your internal IPs) belong
# in the database via 'knowns add', not in this public file.
